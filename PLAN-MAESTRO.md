# Cuenta Vueltas 77 V2

## Objetivo principal

Construir un portal periodístico de automovilismo zonal que sea:

- Profesional y atractivo visualmente.
- Fácil de navegar desde computadora y celular.
- Rápido y liviano.
- Fácil de mantener.
- Fácil y rápido para publicar noticias.

## Problema de la versión anterior

Para publicar una noticia era necesario:

1. Crear una página nueva para la nota.
2. Copiar y modificar la estructura HTML.
3. Agregar manualmente la noticia al inicio.
4. Crear enlaces y rutas.
5. Repetir código y estilos.

En la nueva versión, las noticias se cargarán como contenido y Astro generará automáticamente sus páginas, tarjetas y categorías.

## Datos de cada noticia

Cada noticia tendrá:

- Título
- Bajada
- Fecha
- Categoría
- Imagen principal
- Autor
- Texto de la noticia
- Etiquetas
- Noticia destacada: sí o no

## Reglas del proyecto

1. Cada archivo tendrá una responsabilidad clara.
2. No se repetirá la estructura de las noticias.
3. Los colores y las tipografías se controlarán desde archivos generales.
4. El encabezado y el pie de página se crearán una sola vez.
5. Las noticias se escribirán sin copiar código HTML.
6. La página actual seguirá funcionando hasta que la V2 esté terminada.
